# Ideas & Research — CRM + ERP

> Use esta pasta para depositar qualquer material de referência, pesquisa, prints, benchmarks e ideias brutas que vão alimentar o planejamento do produto expandido.

## Como usar esta pasta

- Adicione arquivos `.md` com notas de pesquisa
- Adicione PDFs, prints ou links de referência
- Não precisa seguir nenhum formato rígido — captura rápida tem mais valor que formato perfeito
- Ao rodar `/reversa-evolve` novamente, o agente lerá esta pasta para enriquecer os artefatos
